# Green-Solvent
Project on green solvent selection for organoelectronics.

Refer to "PolyphaseCopy" with instructions to configure the correct environment. 

"PMMA_PS_Solvents.ipynb" is the most up to date version of the code to predict the solubility of polymers (polystyrene and polymethyl methacrylate) in various solvents given in "Green_Solvent_PBTTT_PMMA_PS.csv"
