# Green-Solvent
Project on green solvent selection for organoelectronics.

Refer to "PolyphaseCopy" with instructions to configure the correct environment. 

"PolymerDopantSolventsDP.ipynb" is the most up to date version of the code to predict the solubility of polymers (polystyrene and polymethyl methacrylate) in various solvents given in "Hansen_Polymers.csv" and "Hansen_Solvents.csv". "Hansen_Polymers_Diff" and "Hansen_Solvents_Diff" are slightly different data sets. 

NOTE: The degree of polymerization in the notebooks should be noted. They are calculated differently in the notebooks.
